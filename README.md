# QuickSort AV2 - Java

Implementação do algoritmo **QuickSort** desenvolvida em Java como parte da avaliação (AV2).

##  Como Executar

1. Certifique-se de ter o **Java JDK** instalado na sua máquina.
2. Abra o terminal na pasta onde está o arquivo `QuickSortAV2.java`.
3. Compile o programa:
   ```bash
   javac QuickSortAV2.java
